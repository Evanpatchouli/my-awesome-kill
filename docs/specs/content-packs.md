# 经典身份局内容包 v1

在「经典三国杀」选将页使用「导入本地 JSON」。可直接导入[示例包](../../packages/duel-core/data/example-content-pack.json)：它加入锦囊【满载而归】及武将「云游客」。不导入时仍使用标准牌表与将池。清除导入只影响下一局；导入内容保留在本次应用会话，不自动安装。

## 文件格式

| 字段 | 约束 |
| --- | --- |
| `schema`、`id`、`version` | 当前 schema 为 1。包 ID 用小写 ASCII 字母、数字、下划线或短横线，首字符为字母，最长 16 字节；`classic` 保留。版本为非空标签。 |
| `cards` | 可省略。每种牌有 `id`、`name`、`description`、`type: "trick"`、`target` 和 `effects`。目标为 `"self"` 或 `"other"`（一名其他参与者）。牌 ID 最长 24 字节。 |
| `deck` | 可省略。每条写 `card`、`suit`、`rank`、`copies`。只引用本包牌种；实体加入基础 104 张牌，不覆盖原牌。花色是 `spade`、`club`、`heart`、`diamond`，点数为 1–13。 |
| `generals` | 可省略。每将有 `id`、`name`、`faction`（`wei`、`shu`、`wu`、`qun`）、`gender`（`male` 或 `female`）、`maxHp`（1–8）和最多 8 个不重复的技能 ID。导入武将也可能由电脑抽到。 |
| `skills` | 可省略。每项有 `id`、`name`、`description`、`timing` 与 `effects`。时机为 `playOnce`（每出牌阶段限一次，可手动发动）、`drawAfter`（自己的摸牌阶段后）、`damageAfter`（自己受到伤害后）。后两者自动执行。 |
| `effects` | 每项 1–4 个操作，按声明顺序入队。当前有 `{"op":"draw","count":3}`（1–8 张）及 `{"op":"recover","count":1}`（1–4 点）。卡牌作用于所选目标，技能作用于自己。 |

新定义的 ID 形如 `demo:more`，前缀必须与包 ID 一致。武将可引用标准技能（如 `wusheng`）或本包技能；标准主公技仍由本局实际身份决定。每包不超过 128 KiB，最多各 32 种牌、技能和武将，最多追加 128 张实体。未知字段、未知操作、重复或缺失的引用均被拒绝。文案不参与规则执行。

## 结算与回放

- 内容定义在开局前校验，每局独立冻结。逻辑牌种、实体 ID 和牌面分开。标准【无中生有】也使用声明式目标与效果，继续保留旧牌种标识，兼容旧录像。
- 自定义锦囊使用现有合法目标生成、材料支付、目标时机、无懈及弃置流程；技能走已有主动/触发注册。文件不能携带可执行脚本，也不会加载联网资源。
- 内容包对局结束后可「导出内容包录像」。回到选将页，使用「打开内容包录像」并拖动进度条逐步查看。录像包含种子、接受的命令及当局完整内容定义；不用再次导入原包，后来修改文件也不会重写录像。录像包含私有对局信息，不应当作匿名公开日志。
- v1 不支持更改胜负或阶段流程、自定义装备、延时锦囊、视为牌、任意条件或脚本、自定义美术、多包合并。未迁移的标准牌和标准技能继续走既有实现。
