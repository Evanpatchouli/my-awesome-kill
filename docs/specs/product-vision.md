# 产品愿景

项目名为 `my-awesome-kill`，中文产品名为「随心杀」。首页题字、应用窗口与启动器使用中文产品名；P1 画廊中的玩法名称为「经典三国杀」。

随心杀计划成为一款单机、可自定义卡牌的类三国杀游戏。它面向桌面和 Android；Android 端复用桌面技术栈，并强制横屏。

项目为自定义卡牌组和规则保留扩展空间。初期阶段目标和界面要求见[路线图](../roadmap/roadmap.md)。经典身份局已可导入[内容包 v1](content-packs.md)，自定义锦囊、武将和部分声明式技能。

本期玩法、牌表与验收边界见[经典双人对局](classic-duel.md)。技术选型见[目标架构](../architecture/target-architecture.md)。
