# 经典三国杀 · 标准身份局

「随心杀」首页进入画廊后选择「经典三国杀」。默认八席，可选 2–10 席。玩家自由选择标准版任意一名武将，电脑从剩余武将中抽取，各席不重名。身份和牌堆随种子洗乱。主公公开并先行，五人及以上主公体力上限和初始体力加一。所有人起手四张，依准备、判定、摸牌、出牌、弃牌、结束推进；正常摸牌两张。过量手牌可多选、撤选，按规定数量一次确认。

## 对局语义

- 各席持有本人的手牌与身份，对其他席公开武将、体力、手牌数、装备与判定区；主公、死亡或终局揭示的身份对全桌公开。私看牌归当前有权决策的角色。原始种子、牌堆顺序和未公开身份不进入前端公开日志。
- 身份配比使用上游 `game/config.json` 的普通模式表。八人是 1 主公、2 忠臣、4 反贼、1 内奸。主公生存且反内全灭则主忠胜，内奸独存胜，其余主公死亡且尚有反忠或多内存活的情形为反贼胜。亡者不再占用存活距离。击杀反贼摸三张，主公误杀忠臣弃全部手牌及装备。
- 实体牌有唯一所在区域。原牌和视为牌分开，转化后仍跟踪材料；判定亮牌、改判和天妒按时机处理。伤害事件和实际体力变化分别记录，濒死按座次求桃；先完成在途清理，再发布终局。
- 改变体力上限时，过高的当前体力随上限一起下调。失去上限至零或更低会直接发起死亡。若技能取消这次死亡，角色保留结算后的体力和上限，身份公开程度沿用当前局面。救援过程中，下一位救援者按固定座次从仍存活的角色中确定。
- 普通出牌先选牌、再指定合法角色、确认。每个锦囊目标独立接受无懈；借刀需按次序指定持武器者和受杀者。选择成本、目标数、时机、角色、事件号与版本均由核心校验。非法或过期输入不改变局面，重复提交同一版本只可能接受一次。
- 单机对手消费同一套合法候选，按已公开的身份线索采取行动。表现层读取结构化事件播放发牌、出牌、响应与扣血等动效。动画、视觉选中状态和设备刷新率不影响规则的结果。

经典模式的行为用例位于 `packages/duel-core/src/classic/*tests*`、`skills/tests` 和 `packages/duel-core/tests`。底座其余机制的迁移范围与实测证据见[迁移计划](../exec-plans/active/p1-engine-migration.md)。

## 对局操作界面

自己一侧从左到右是装备栏、手牌画廊、技能按钮和武将牌。普通模式四个装备槽等高铺满，与武将牌共享高度和上下留白。体力竖排在武将牌内右下角。没有可提交选项的技能置灰；从手牌选择主动使用的牌时，规则说明和操作按钮显示在画廊上方，不设倒计时。

放弃和无需选择的响应点选即生效。只有一张可用的闪时，「使用闪」直接打出该牌。需要选牌的技能、弃牌和拼点在手牌画廊选自己的牌，已选牌抬起，取消收回选择，确认后才结算。

从牌堆选牌或整理牌序，以及选择对手的牌时，候选牌放在中央。确认、取消、移动牌序等操作放在中央牌区下方、手牌画廊上方。可见牌显示正面；对手的随机手牌显示匿名牌背，点任意一张都按原规则随机结算。普通摸牌自动结算。
