# 经典三国杀 · P1 双人对局

首页显示游戏题字“随心杀”。在模式画廊选择“经典三国杀”进入双人对局。

同桌两席，人类选张飞（男，4体力，咆哮）或黄月英（女，3体力，集智、奇才），电脑使用另一位。本期采用标准牌与普通回合规则的双人明将对决，无身份、主公加成或替补武将。双方各摸四张，玩家先行，首回合照常摸两张。体力、装备、判定区和手牌数公开，对方手牌内容隐藏。体力降至零或以下进入濒死，从当前回合角色起依次询问用桃，救回到至少一点才脱离濒死，未能救回则另一方获胜。

## 内容来源与牌区

对照 noname 的 apps/core/character/standard/{sort,character,translate}.js 的 2008 标准组，以及 apps/core/card/standard.js 的 list。选取前 104 个实体行，即经典标准牌，四种花色各 26。末尾四张 EX（黑桃2寒冰剑、梅花2仁王盾、红桃Q闪电、方片Q无懈可击）属于附加牌；标准牌中的另一张闪电和三张无懈可击保留。每个实体即使牌面相同也拥有独立编号。

- 基本 53：杀30、闪15、桃8。
- 装备 17：诸葛连弩2，雌雄双股剑、青釭剑、青龙偃月刀、丈八蛇矛、贯石斧、方天画戟、麒麟弓各1，八卦阵2，六匹坐骑各1。
- 锦囊 34：五谷丰登2、桃园结义1、南蛮入侵3、万箭齐发1、决斗3、无中生有4、顺手牵羊5、过河拆桥6、借刀杀人2、无懈可击3、乐不思蜀3、闪电1。

牌在摸牌堆、手牌、装备区、判定区、结算桌面、弃牌堆中各居一处。摸牌堆耗尽时用种子随机数重洗弃牌堆。牌表与行为分别注册。未结束的牌留在结算区，避免洗回同一张正结算的牌。

## 决策与时序

- 回合依序处理判定（后放先判）、摸两张、出牌、逐张弃至手牌数不超过当前体力、结束。玩家可主动结束出牌。没有合法可选响应时自动放行。
- 目标由使用者、两人距离、武器范围、同名延时锦囊、区域内可选牌等条件确定。唯一目标显示在操作文字中。普通杀限出牌阶段一次，连弩和咆哮解除次数限制。双人基础距离一，进攻马减一、防御马加一，最终至少一。奇才免除锦囊距离限制。方天画戟增加攻击范围，双人局没有额外对手。借刀的杀可以指回锦囊使用者。
- 集智可在使用普通锦囊（含无懈可击）时先摸一张。每个锦囊目标独立结算。无懈链按优先顺序询问，连续无人应答后按奇偶抵消；无懈可被后续无懈抵消。五谷揭出的剩余明牌在无懈响应前已经公开，双方随后按顺序选择；随机抽取对方手牌时只可选隐藏手牌区，公开区域按实体选择。延时锦囊于判定生效前接受无懈。
- 八卦阵可在需要闪时选择判定；红色提供虚拟闪，黑色后仍可选择手牌闪。青釭剑只在该杀期间忽略防具。技能和装备的可选支付由当前决策者选定，不自动消耗玩家牌。
- 电脑使用同一套合法选择，按当前选项的战术优先级行动，例如濒死自救、有效防御、装备与伤害机会、结束出牌；同分按稳定顺序。核心由随机种子与逐次输入决定，动画、定时器和持久化均在核心外。
- 每次 UI 指令携带上一帧的状态版本和选项标识。错误的时机、版本、选项及终局操作均拒绝，状态不变；新局独立创建。
