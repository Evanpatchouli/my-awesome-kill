# 路线图

## P1

基于 `.reference` 和本项目选定的技术栈，搭建一个初版 MVP 应用，要求实现以下功能：

1. 搭建一个可运行的最小化单机应用
2. 应用首页不要做成 admin 系统那样的侧栏+主视图布局，而是独立首页，在右下区域提供一个大大的圆形按钮"开始游玩"（文本分两行，"开始"在上，整体文案居中）；首页顶部分成左右两部分，均一字排开摆放圆形按钮（圆形图标按钮+下方文本），右侧提供 "我的" 和 "设置"，左侧提供 "尽请期待"。点击任何按钮都会进入相应的独立页面，页面左上角提供"返回"图标按钮
3. 点击 "开始游玩" 进入游戏主界面，以画廊形式展示所有可用的游戏模式，目前只提供一个模式 "经典三国杀"
4. 程序设计应当具备高可拓展性，以避免未来支持自定义卡牌组和规则等特性时面临大量重构

### P1 对局底座与经典模式

P1 将 noname 的通用对局机制及其可观察行为迁移至本项目，以 Rust 作为规则底座，形成新的内容接口。兼容目标覆盖事件时机、合法选择、技能触发与优先级、卡牌和区域流转、角色生命周期、身份结算、AI 可见信息及呈现时序。既有 JavaScript 扩展脚本无需原样运行。以可执行的规则轨迹对照参考实现，记录并验证有意修正的异常。

经典三国杀作为首个模式，支持从 2008 版标准包全部 25 名武将中自选，保留 104 张经典基础套牌的实体牌面。对局内尽量使用参考项目的原始武将、卡牌资源，并按实际结算显示装备、出牌与伤害反馈。玩家在弃牌阶段可以多选、撤选并一次确认。

现有双人原型的测试与制品属于迁移前基线。完整 P1 验收涵盖底座机制、多人经典模式、真实运行入口和独立复核。
