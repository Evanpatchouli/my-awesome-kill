# Documentation map

只在文档能降低未来重复调查成本时维护它。开始非平凡任务时先看本页和 `context/README.md`，再按任务读取少量相关文档。

| 目录 | 保存什么 | 不保存什么 |
| --- | --- | --- |
| `context/` | RAG 入口、模块索引、检索提示 | 大段复制源码 |
| `specs/` | 产品/行为契约、对外语义 | 具体实现细节 |
| `architecture/` | 模块边界、数据流、系统结构 | 一次性任务过程 |
| `decisions/` | ADR：决策原因、替代方案、后果 | 未落地的随手想法 |
| `runbooks/` | 开发、测试、部署、排障操作 | 架构讨论 |
| `knowledge/` | 稳定、可复用的工程经验 | 临时日志和猜测 |
| `exec-plans/` | 跨多步、需要持久化的执行计划 | 简单 TODO |

事实优先级：可重复运行结果 / 测试 / 当前代码与配置 > 正式文档 > 历史讨论。
